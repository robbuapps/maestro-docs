## Empresas

Na tela **Empresas**, o usuário pode visualizar a lista de empresas cadastradas. A Gerente do Ambiente pode criar novas empresas. Essa funcionalidade centraliza a gestão das empresas que farão parte das estratégias de comunicação dentro do Maestro.

<Warning>
Uma empresa inativa ou excluída deixa de operar no ambiente: os usuários dela não conseguem entrar no Maestro (nem por senha, nem por SSO), o Token de Integração dela é recusado pela API e os arquivos das contas SFTP dela não são processados.
</Warning>

## Usuários

Na seção **Usuários** é possível listar e gerenciar todos os usuários cadastrados na plataforma. Cada usuário pode ter nenhum, um ou vários Perfis de Acesso.

### Perfis de Acesso

O que cada usuário pode fazer no sistema é controlado pelo Perfil de Acesso atribuído a ele, dentro do que a própria empresa já tem concedido. Veja [Como Funcionam as Permissões](/permissoes/visao-geral).
