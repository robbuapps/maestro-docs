## Empresas

Na tela **Empresas**, o usuário pode visualizar a lista de empresas cadastradas e, conforme as permissões de Empresas, criar e editar empresas. Essa funcionalidade centraliza a gestão das empresas que farão parte das estratégias de comunicação dentro do Maestro.

- O campo **Tipo de empresa** só aparece para usuários da Administradora do sistema. Para os demais, a empresa criada é sempre do tipo Parceira. Veja [Perfis de Uso](/introducao/perfis-de-uso).
- Cada ambiente tem um único Gerente do Ambiente e no máximo uma Administradora do sistema ativa.
- Nome e CNPJ não podem ser alterados depois da criação.
- Só Gerente do Ambiente e Administradora do sistema ativam ou inativam empresas e marcam **Ocultar dos dashboards**. Essa opção não está disponível para empresas desses dois tipos.
- Uma Parceira com permissão de editar empresas edita só a própria empresa e, nela, só os segmentos. Sem a variante "todas as empresas" da permissão de Segmentos, ela só mantém ou remove segmentos que a empresa já tem.

<Warning>
Uma empresa inativa ou excluída deixa de operar no ambiente: os usuários dela não conseguem entrar no Maestro, o Token de Integração dela é recusado pela API e os arquivos das contas SFTP dela não são processados. Para reverter, veja [Troubleshooting](/central-de-suporte/troubleshooting).
</Warning>

## Usuários

Na seção **Usuários** é possível listar e gerenciar os usuários cadastrados na plataforma. Cada usuário pode ter nenhum, um ou vários Perfis de Acesso.

A lista mostra os usuários da própria empresa. Ver e gerenciar usuários de outras empresas, incluindo o filtro por empresa, exige a variante "todas as empresas" da permissão de Usuários.

### Perfis de Acesso

O que cada usuário pode fazer no sistema é controlado pelo Perfil de Acesso atribuído a ele, dentro do que a própria empresa já tem concedido. Veja [Como Funcionam as Permissões](/permissoes/visao-geral).
