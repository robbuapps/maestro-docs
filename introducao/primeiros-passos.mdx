A tela de login do Maestro é responsável pelo gerenciamento de acesso e autenticação de usuários, oferecendo dois mecanismos complementares:

- Login por e-mail e senha
- Login com SSO (Single Sign-On)

## SSO (Single Sign-On)

A autenticação pode ser configurada para permitir login via credenciais corporativas. Atualmente o Maestro possui integração com o seguinte motor de SSO:

- Microsoft Entra ID (Azure AD)

Para utilizar o SSO, acesse **Configurações > Empresa** e adicione o ID da aplicação do Microsoft Entra ID (Azure AD) no campo designado. Dessa forma, usuários podem acessar o sistema sem criar novas senhas, utilizando suas credenciais da organização — o que traz mais segurança e praticidade.

<Warning>
Para que o SSO seja efetivado, libere a URL `https://api.maestro.robbu.global/v1/auth/login/sso/callback` no seu aplicativo de SSO, para que o retorno possa ser validado.
</Warning>

<Note>
O login via SSO valida usuários já cadastrados na plataforma Maestro. Antes de testar o SSO com um usuário, confirme que ele já está cadastrado na tela de Usuários.
</Note>

Também é possível configurar o ambiente para permitir que usuários acessem a plataforma **utilizando apenas o SSO** (sem a opção de e-mail e senha).
